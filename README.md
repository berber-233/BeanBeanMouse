# BeanBeanMouse（豆豆鼠）外贸平台演示原型

一个可直接在浏览器中运行的外贸 B2B 平台第一版原型，覆盖完整业务闭环：

**品牌吉祥物（定稿）**：豆豆鼠（BeanBeanMouse）——矢量手绘 Q 版金丝熊仓鼠送货员：
圆润身形、鼓鼓颊囊、红色围巾，暖黄白配色与网站主题一致。
- 主吉祥物 `assets/mascot-vector.svg`（矢量：导航 Logo / 帮助按钮 / 镖局场景头像），
  `assets/mascot-vector.png`（OG 分享图与浏览器图标）；
- 打赏吉祥物 `assets/tip-hamster-empty.svg`（空碗）/ `assets/tip-hamster-full.svg`（金币碗，含金币弹出动画）；
- 点击网站右下角吉祥物可打开"网站使用帮助"。

**买家链路**：搜索 / 筛选产品 → 查看详情 → 发送询盘 → 在我的询盘查看供应商回复
**卖家链路**：发布产品（预发布）→ 等待平台审核 → 上架后接收询盘 → 回复买家 → 数据总览
**管理员链路**：审核产品（通过/驳回）→ 认证企业 → 管理用户 → 查看平台数据与操作留痕
**资讯链路**：贸易资讯栏目按你关注的地域聚合权威政策与行业信息，每条附可查询来源

## 如何打开

双击 `index.html`（推荐使用 Chrome 或 Edge）。无需安装任何软件，所有数据保存在你本地浏览器的存储中，刷新不丢失。

## 演示账号（一键体验，无需注册）

- 首页右上角「登录」→ 选择「以买家身份体验」或「以卖家身份体验」
- 第三个角色「以平台管理员身份体验」可进入平台管理后台
- 也可直接以游客身份浏览和发送询盘

## 功能清单

- 语言切换：顶栏「中文 / EN / 其他」；点「其他」可任选 25 种语言（含各语言本地名称与国旗），
  或一键「跟随浏览器语言」。首次进入默认英文引导，并弹出轻量语言引导条；界面文案未完全覆盖的语言自动回退英文
- 按浏览者语言展示产品：卖家以自身语言发布（发布时可选择“产品语言”，默认按卖家地区自动判断），
  买家浏览时产品标题 / 描述 / 卖点自动翻译为买家所选语言（翻译结果本地缓存）；
  产品详情页提供「原文」折叠块，可对照卖家原始语言，阿拉伯语 / 波斯语界面自动切换 RTL 方向
- 为译文预留版面：产品卡片标题支持三行换行，正文与翻译块启用自动换行，长译文不会被截断或撑破布局
- 首页：搜索、热门行业、精选产品、平台保障介绍
- 产品市场：按行业 / 价格区间 / 最小起订量 / 产地 / 认证筛选，支持排序
- 产品详情：规格参数（含 HS 海关编码）、参考汇率、贸易术语说明（Incoterms® 2020）、清关合规提示、供应商信息
- 防伪验证：每件产品拥有唯一防伪码（如 `BBM-P1-62`），详情页展示“扫码验真（演示）”与验证结果；
  页脚提供「防伪查询」（输入防伪码验真）与「验证本站真伪」（官方平台认证，防钓鱼仿冒）入口
- 询盘与报价：买家填写期望支付方式；卖家以结构化报价单回复（单价 / 贸易术语 / 支付方式 / 有效期 / 交期）
- 单证与打印：报价单 / 形式发票按国际贸易通行格式生成（编号、日期、买卖双方、HS 编码、数量单价总价、条款、签章），可一键打印或另存为 PDF；报价表单内置"单证格式参考"
- 卖家工作台：数据总览、产品管理、发布产品（含图片配色预览）、询盘回复
- 买家中台：我的询盘（含供应商回复）、收藏
- 平台管理后台：数据看板（行业/国家分布）、产品审核（合规风险提示、通过/驳回）、
  企业认证、用户管理（冻结/解冻）、操作日志（审计留痕）
- 贸易资讯：政策速览（基于 2026 年公开报道）、按分类与关注地域筛选、权威信息源目录、
  参考汇率条、信息同步与信息源接入说明，每条资讯附可查询的官方来源链接
- 目标市场合规清单：发布产品时选择目标市场，详情页按市场提示常见认证与合规要求（CE、CBAM、FCC、FDA、PSE 等）
- 实时翻译（仅供参考）：撰写询盘 / 报价备注时实时显示译文参考，已发消息可一键查看译文。
  优先调用第三方机器翻译服务（MyMemory，备用 LibreTranslate 公共实例），结果本地缓存；
  无网络时自动降级为内置离线短语库，所有译文均标注「仅供参考，正式沟通以原文为准」。
  海外免费翻译接口在部分网络环境下可能无法访问，届时会自动使用离线兜底
- 预发布审核流程：卖家发布的产品需管理员审核通过后才对外可见
- 合规演示元素：审核依据说明、违禁词/侵权风险提示、操作留痕、协议与举报入口占位

## 后续完善方向

当前为可评估的设计原型，以下方向建议在正式版本中完善：

1. **真实后端与账号体系**：接入数据库、注册登录/邮箱验证、会话与权限管理，替换 localStorage 演示数据；
   询盘、报价、消息通过后端落库并支持邮件/站内通知。
2. **即时沟通**：站内实时聊天（WebSocket）、已读回执、会话存档，与询盘/报价单打通；
   实时 AI 翻译在服务端做鉴权与额度管理。
3. **防伪体系落地**：防伪码改为权威验真机构签发并接入扫码验真（真实二维码）、区块链存证、
   产品溯源（生产批次/物流轨迹）；平台“验证本站真伪”接入域名备案与数字证书校验。
4. **交易闭环**：在线支付与信用证辅助、订单合同在线签署（电子签）、物流轨迹跟踪、
   履约保障（验货、保险、纠纷仲裁）与信用评分体系。
5. **合规深化**：按目的国法规生成出口合规清单（含动态更新）、贸易管制筛查（出口管制/制裁名单）、
   产品认证证书库与到期提醒、欧盟 CBAM 申报数据对接。
6. **资讯自动化**：接入官方 RSS/API 自动聚合贸易政策，增加订阅推送（邮件/站内）与多语言自动翻译校对。
7. **国际化**：补齐 25 种语言的完整界面文案（当前未覆盖语言回退英文）、货币换算与本地化报价、
   各国清关与税务参考。
8. **性能与安全**：HTTPS、静态资源 CDN、服务端渲染/SEO、反爬与风控、数据备份与审计合规（GDPR/个保法）。

## 目录结构

- `index.html` — 页面入口
- `styles.css` — 全部样式
- `data.js` — 演示数据与中英文文案
- `api.js` — 前端数据层（阶段 0：mock 模拟后端，预留 http 接入）
- `app.js` — 页面路由与业务逻辑
- `backend/` — 后端服务（阶段 1 MVP：Node 内置 HTTP + SQLite，零依赖；详见 backend/README.md）
- `screenshots/` — 各页面效果截图
- `test/` — 自动化验证与截图脚本（基于 Playwright，可重复运行）
- `docs/` — 后端设计文档（ER 图、OpenAPI 接口定义、建设路线）
- `project-history/` — 项目记录（聊天记录、设计决策、部署记录）

## 说明

这是用于评估设计的第一版原型：产品图片为程序生成的占位图，数据为演示数据，联系通过站内询盘模拟实现（真实邮件通知需接入邮件服务）。后续可在此基础上接入真实后端、账号系统、即时消息、邮件通知与正式的合规条款。

## 上线与合规提示

- 翻译服务：演示默认直连第三方免费接口（无需密钥、有每日额度）。正式上线建议申请带密钥的翻译服务
  （如 DeepL / Azure Translator），并把密钥保存在后端，避免前端泄露与额度滥用。
- 免责声明：所有机器译文旁均已标注「仅供参考，不构成要约或承诺」，正式交易以原文与签署合同为准。
- 预发布：产品发布后处于「待审核」状态，管理员通过后才对外可见，符合内容审核的基本要求。
