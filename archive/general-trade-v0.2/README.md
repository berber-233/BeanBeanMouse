# 综合外贸站快照（v0.2，2026-09-16 归档）

这是"豆豆鼠综合外贸平台"版本的代码快照：机械设备 / 电子电器 / 纺织服装 / 家具家居 / 宠物用品
多品类，买卖双方撮合模式（卖家主页、双方互评、佣金撮合）。

**2026-09-16 起主线切换为宠物用品自营外贸站（pet0.2）**，本站点不再继续开发，
作为"未完成 idea"保留——等宠物品类跑通后，其中的外贸流程模块（物流、合规、单证、售后）
会按需搬回新站。

## 和当前主线的区别

| | 本归档（v0.2） | 当前主线（pet0.2） |
| --- | --- | --- |
| 品类 | 机械 / 电子 / 纺织 / 家具 / 宠物… | 仅宠物用品（8 个细分） |
| 交易模式 | 买卖双方撮合 | 平台自营，用户向平台询问 |
| 注册 | 买家 / 卖家 双向 | 客户 / 商家（供应商合作） |

## 怎么单独跑起来

这是纯静态站，但**依赖仓库根目录的 `assets/`**（归档时没有复制资源，避免仓库体积翻倍）。
直接打开 `index.html` 即可，或在仓库根目录起一个静态服务器后访问
`/archive/general-trade-v0.2/index.html`。

> 注意：`sitemap.xml`、`robots.txt`、`_redirects`、`_headers` 是当时针对 `beanbeanmouse.com`
> 的线上配置，**已不生效**，仅作留档。
