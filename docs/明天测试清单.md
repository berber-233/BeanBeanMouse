# 明天测试清单（v0.2 试用）

> 目标：用 15–20 分钟把主链路走一遍，确认"能用"。
> 每步都写了**预期结果**；不符合预期的，把那一步的**提示语/截图**发我，我按图定位。

## 1. 新客户注册 → 邮箱验证（约 3 分钟）

1. 首页右上角 **登录 → 还没有账号？注册**
2. 填姓名 / 你的真实邮箱 / 密码（≥8 位，含字母和数字）/ 身份选"客户"
3. 过人机验证 → 提交
4. **预期**：弹出"注册成功，还差一步"，提示①去邮箱点验证链接 ②（这一步现在不需要审核）
5. 去邮箱收信（标题「[豆豆鼠] 请验证您的邮箱」，发件人 `BeanBeanMouse <no-reply@mail.beanbeanmouse.com>`）
6. 点邮件里的「完成邮箱验证」
7. **预期**：页面显示验证成功 → 用该邮箱+密码登录 → **直接进入工作台**（不再需要等审核）

> 没收到邮件？先看垃圾箱；仍没有就点注册弹窗里的"重新发送验证邮件"。

---

## 2. 买方发询盘（带附件 + 名片）（约 3 分钟）

1. 用**买方演示账号**登录（或第 1 步注册的新账号）
2. 进 **产品市场** → 随便点一个商品 → **发送询盘**
3. 填数量、需求；**附上一张图片**（附件入口已恢复）；如有名片可勾选"附上名片"
4. **预期**：提交成功后，工作台"我的询盘"里能看到这条询盘，**附件能点开看到图**
5. 再试首页的 **批发询价**（三步对话：目标市场 → 品类 → 采购量/目的国/联系方式）
6. **预期**：提交后同样出现在"我的询盘"

---

## 3. 管理端看询盘并报价（约 3 分钟）

1. 用**管理员账号**登录 → 工作台
2. **预期**：首页顶部有 **系统自检** 卡片，四项都是绿点：邮件通道 ready、对象存储 r2 ready、注册需邮箱验证=已开启、人工审核=已关闭
3. 进 **客户询盘** → **预期**：能看到第 2 步的询盘，含联系人、邮箱、国家、附件、名片（点"查看名片"能看图）
4. 在该询盘里填价格 / 贸易术语 / 交期 / 付款方式 → **发送报价**（可附规格图）
5. 切回**买方账号** → 我的询盘 → **预期**：能看到报价（金额、术语、交期）

---

## 4. 商品管理（上传真实商品）（约 3 分钟）

1. 管理员账号 → 工作台 → **商品管理**（新增的页签）
2. **发布产品** → 填中英文标题、价格区间、MOQ、交期、描述 → **选择一张真实商品照片**
3. 提交 → **预期**：商品进入列表，状态"已上架"（管理员发布直接上架）
4. 打开首页/产品市场 → **预期**：能看到这件商品，**卡片用的是你上传的照片**
5. 回商品管理：**编辑**（改价格）→ 刷新后价格生效；**下架/删除**也能生效

> 提示：**卖方账号**（seller@beanbeanmouse.com）发布商品前需要先提交企业认证并由管理员通过（这是正常规则）；
> 测试时用**管理员账号**发布最省事（自营模式）。

---

## 5. 忘记密码（约 2 分钟，可选）

1. 退出登录 → 登录 → 点 **忘记密码？**（或在密码框右边）
2. 填邮箱 → 提交 → 收邮件（标题「[豆豆鼠] 重置您的登录密码」，1 小时有效）
3. 点邮件里的「设置新密码」→ 设新密码 → **预期**：能立刻用新密码登录，旧密码失效

---

## 6. 用户管理（约 2 分钟）

1. 管理员 → 工作台 → **用户管理**
2. **预期**：能看到所有账号（含你自己刚注册的），每行有"邮箱已验证/未验证"标记
3. 对某个测试账号点 **冻结** → 该账号立刻无法登录（连旧登录态也会失效）→ 再点 **解冻** 恢复

---

## 7. 法规页与其它（1 分钟）

1. 页脚：用户协议 / 隐私政策 / 退换货政策 / 违规举报 → **预期**：都是真页面，顶部有「草案 · 待法务审定」横幅
2. 关于我们 → **预期**：有"运营主体：主体信息待补充"的说明（还没注册公司，如实标注）

## 测试时怎么反馈最有用

1. **哪一步**（例如"第 3 步，管理端报价"）
2. **屏幕上看到什么**（提示语原文最好）
3. 有截图更好
4. 如果是"没反应"，说明是点了没动、还是转圈很久
