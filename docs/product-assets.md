# 真实商品素材方案

## 现状

- 演示商品图由程序生成（SVG 渐变 + 首字母占位）。
- 本轮新增「真实商品图」管线：卖家在发布/编辑商品时可直接上传实拍图（JPEG/PNG/WebP，
  最多 8 张，单张 ≤4MB），页面会自动用真实图替换占位图，无图时回退占位图。

## 使用方式

1. 卖家登录 → 工作台 → 发布产品 / 编辑产品。
2. 在“真实商品图（可多选）”上传实拍图，可即时预览与移除。
3. 保存后：产品卡片、产品详情画廊、搜索推荐均优先显示真实图。

## 供图规范（写给供货商）

- 格式：JPEG（推荐）/ PNG；单个 ≤4MB；建议最长边 ≥1200px、正方形或 4:3。
- 白底或浅灰底产品主图 1 张；细节/尺寸/包装图 2–3 张更佳。
- 不要带他人 Logo、水印、联系方式；不得使用未经授权的品牌图。
- 命名建议：品类-型号-主图/细节（例：hamster-cage-h80-main.jpg）。

## 后续演进

- 小试用阶段：图片随数据存本地/后端（对象存储就绪后切 R2/S3，前端已按 `images[]` 结构存储）。
- 可选：给演示商品生成 AI 实拍风占位图（需启用 imagegen 的 API/CLI 通道并提供密钥），
  可一次生成一组商品图放进 `assets/products/<id>/` 并替换 seed 数据。
- 平台角度：把“真实商品图数量/清晰度”纳入发布质量分与审核项。

## 文件

- 上传/回退逻辑：`app-core.js`（`productImages / productImgUrl / productMainImg`）
- 发布与预览：`app-pages.js`（发布表单图片区、`productImgListHtml`）
- 显示：产品卡片、详情画廊、相关推荐、卖家主页
