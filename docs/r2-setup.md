# 开通 Cloudflare R2（附件与商品图上传）手册

> ✅ **状态：已完成（2026-09-30）**
> R2 已开通、桶 `beanbeanmouse-files` 已创建、绑定已写入 `wrangler.jsonc`，
> 线上实测：上传文件 → 挂到商品 → 前台可公开读取 → 摘除，全部通过；
> 询盘附件与商品图上传入口已恢复可见。
>
> **重要提醒**：本项目由 `wrangler.jsonc` 配置管理，Cloudflare 控制台的
> "Settings → Functions → R2 bucket bindings" 是**只读**的（Add 按钮点不动），
> 绑定必须写在配置文件里——这也是为什么 D1 数据库绑定一直是在 wrangler.jsonc 里维护的。

> 用途：让**询盘/报价的附件**（图片、ZIP/RAR/7Z）与**商品图片上传**真正可用。
> 现状：这两类上传入口被暂时隐藏（CSS 规则 `.needs-r2`），后端存储适配器在 R2 未绑定时返回 503。
> R2 开通并绑定后，改一行规则即可恢复全部入口。

## 二、你要做的（约 5 分钟）

### 第 1 步：开通 R2

1. 登录 `https://dash.cloudflare.com/`
2. 左侧菜单找到 **R2**（Object Storage）
3. 点 **Enable / 开通**；若提示添加订阅或支付方式，按提示完成

### 第 2 步：创建存储桶

1. R2 → **Create bucket**
2. 名称填（必须一致，代码里写的就是这个名字）：

   ```
   beanbeanmouse-files
   ```
3. 位置（Location）选 **Automatic**；若想更省延迟，可按主要买家地区选：美洲 `ENAM`、欧洲 `WEUR`、亚太 `APAC`
4. 其余保持默认（**不要**开启 Public access，附件只通过站点接口访问）

### 第 3 步：把这个桶绑定到 Pages 项目

1. 左侧 **Workers & Pages** → 选择项目 **beanbean-mouse**
2. **Settings** → **Functions**（或 **Bindings**）→ 找到 **R2 bucket bindings** → **Add**
3. 按下表填：

   | 字段 | 值 |
   | --- | --- |
   | Variable name | `FILES`（必须完全一致） |
   | R2 bucket | `beanbeanmouse-files` |
   | Environment | Production 与 Preview 都勾上 |

4. 保存（保存后需要一次新部署才生效，我会一起做）

### 第 4 步：告诉我"R2 已绑定"

我会做这几件事（你不用动手）：

1. 打开仓库里 `wrangler.jsonc` 中这段注释（把 R2 绑定写进部署配置）：
   ```jsonc
   "r2_buckets": [{ "binding": "FILES", "bucket_name": "beanbeanmouse-files" }],
   ```
2. 删掉隐藏上传入口的那条 CSS 规则（`.attach-field.needs-r2, .field.needs-r2 { display:none }`）
3. 重新部署
4. 实测：上传一张图片 → 返回 200 → 在询盘里能看到并下载附件

## 三、开通后能用到什么

| 功能 | 说明 |
| --- | --- |
| 询盘附件 | 客户/你在询盘里附图片或压缩包（ZIP/RAR/7Z），对方可直接下载 |
| 报价附件 | 报价时附规格书、装箱图等 |
| 商品图片上传 | 发布商品时上传真实商品照片（替换现在的概念图） |

**已有安全限制**（代码里已经写好，无需额外配置）：

- 单文件上限 `MAX_FILE_SIZE`（当前 10 MB）
- 类型白名单：`jpg/png/gif/webp` + `zip/rar/7z`
- 存储桶保持私有，读写都经过 `/api/files/...`，不会变成公开图床
- 下载链接由后端鉴权后返回，避免他人枚举文件

## 四、备选方案（如果被支付方式卡住）

| 方案 | 说明 |
| --- | --- |
| **阿里云 OSS**（推荐备选） | 与 R2 同为 S3 兼容对象存储，**支付宝/对公账户即可付款**，无需外币卡。我可以写一个 OSS 存储适配器，功能等价（上传/下载/鉴权都走我们的接口，桶保持私有）。缺点是要多维护一套签名逻辑 |
| 继续关闭附件 | 网站其余功能不受影响；名片已经不走 R2（它以图片数据存在个人资料里），所以名片上传现在就是可用的 |
| 以后开通外币卡后再用 R2 | 到那时只需回到本文第 1–3 步 |

## 五、可选优化（开通后我可以顺手做）

- **生命周期规则**：自动清理 180 天前、且未被任何询盘引用的上传文件，避免垃圾占空间
- **图片自动压缩**：上传时按用途（商品主图 / 附件）压缩到合理尺寸（名片已经这么做了）
- **缩略图**：商品列表用缩略图，详情页用原图，省流量
