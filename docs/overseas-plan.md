# BeanBeanMouse（豆豆鼠）面向国外用户改进方案

> 状态：设计草案，待确认关键问题后细化并执行。
> 核心变化：从“中文原型 + 英文翻译”升级为“以海外买家为中心”的产品：
> 语言、货币、支付、信任、合规、部署、客服全链路国际化。

## 1. 产品定位与语言

1. **英文为主界面**：现有默认英文 + 25 语言选择已具备基础；补齐 25 种语言完整界面文案
   （当前未覆盖语言回退英文），重点保证：EN、ES、FR、DE、PT、AR、RU、JA、KO、HI、ID、TH、VI、TR。
2. **内容多语言数据化**：产品标题/描述/卖点改为“源语言 + 目标语言”双轨存储
   （`product_translations` 已设计），发布时卖家填母语，系统用 DeepL 翻译 + 人工校对入口；
   机器翻译结果保留“仅供参考”标注，避免贸易纠纷。
3. **本地化格式**：日期/时区按用户地区；货币多币种展示（按实时汇率换算，结算是美元锚定）；
   数量单位（pcs/set/ton/kg）已有，补充英寸/厘米、磅/千克等显示切换。

## 2. 信任与防伪（海外买家最看重）

1. **供应商验证升级**：营业执照 + 实地验厂/视频验厂、出口资质、第三方检测报告（SGS/Intertek）
   上传与展示；认证标识分级（已认证/验厂认证/金牌供应商）。
2. **防伪与溯源**：防伪码权威签发 + 真实二维码扫码验真 + 区块链存证（选服务商）；
   产品溯源（批次、生产日期、物流轨迹）对外展示。
3. **买家保障**：交易保险（如信保）、验货服务（第三方）、纠纷仲裁流程；
   卖家履约评分与差评体系，公开透明的退款/索赔政策。
4. **网站可信度**：英文版帮助中心/FAQ、Trustpilot/Google Reviews 集成、SSL 证书、
   清晰的 Terms / Privacy / 联系方式，避免“看起来像中国钓鱼站”。

## 3. 支付与计费（面向海外）

1. **收款通道**：Stripe（全球卡）为主 + PayPal（欧美习惯）+ 银行电汇（B2B 大额）；
   或 Adyen 多通道；全部走托管支付，避免自建收单（PCI 合规成本极高）。
2. **计费模式（待确认）**：
   - 免费注册 + 询盘扣点（类似 Alibaba 的“询盘购买”）；
   - 会员订阅（卖家月费 + 增值包：认证、置顶、翻译额度）；
   - 交易佣金（成交后按比例抽成，需要成交闭环）。
3. **税务**：B2B 出口通常零税率/逆向征税，需按目的国处理 VAT/GST 申报；
   卖家收款主体建议海外公司（见第 5 节）。

## 4. 部署与技术架构（海外访问）

1. **海外云**：AWS/GCP 或 Vercel + 托管 PostgreSQL（RDS/Supabase）；
   服务器地域按目标市场选（欧盟用法兰克福/爱尔兰，北美用 us-east，东南亚用新加坡）；
   CDN（Cloudflare）全球加速静态资源与图片。
 2. **域名与品牌**：建议购买 `.com` 主域名（如 beanbeanmouse.com），配置 SPF/DKIM/DMARC 防邮件伪造。
3. **邮件送达**：SMTP 直连替换为专业 ESP（SendGrid/Mailgun/SES），
   提高海外送达率（避免进垃圾箱）；事务邮件与营销邮件分通道。
4. **监控与安全**：日志与告警（Sentry/云监控）、WAF（Cloudflare）、
   定期备份、渗透测试（上线前）、HTTPS 全站。

## 5. 法律与合规

1. **公司主体**：建议注册海外实体（香港/新加坡/美国 LLC）作为收款与签约主体，
   否则 Stripe/PayPal 可能因行业或地区限制拒收。
2. **法律文件**：英文 Terms of Service、Privacy Policy、Refund Policy、DMCA Policy、
   Cookie 同意横幅（GDPR）、数据主体权利（删除/导出）。
3. **数据合规**：GDPR（欧盟用户）— 数据最小化、DPA、跨境传输条款；
   CCPA（加州用户）— 不卖数据声明；儿童保护 COPPA（禁止 13 岁以下注册）。
4. **行业合规**：出口管制筛查（制裁名单）、产品合规（CE/FCC/FDA 等已有提示）、
   反洗钱（大额收款 KYC，配合支付通道要求）。

## 6. 运营与客服

   AI 客服辅助（多语言）兜底。
2. **内容运营**：英文/多语言博客与贸易指南（SEO）、Google Business、行业展会；
   资讯栏目增加海外权威源（已有 WTO/USTR/EU 等）。
3. **卖家招募**：面向海外供应商的多语言入驻页、认证流程与激励政策。

## 8. 在线支付与托管交易（三选一，需你确认）

### 方案 A：纯撮合（零支付风险，最快上线）

- 平台只做信息撮合、沟通与订单确认，付款在平台外完成（电汇/线下）；
  平台佣金通过"卖家申报成交额 + 抽查"或按订单收取。
- 优点：无需支付牌照、无拒付风险、不触碰资金、1–2 周即可接入。
- 缺点：佣金难以完全控制、买家缺托管保障、信任感弱、易被绕单。
- 适合：海外主体未落地前的过渡阶段。

### 方案 B：平台代收 + 自动分账（推荐起步，Stripe Connect 模式）

- 流程：买家下单 → 付款进入平台托管账户（Stripe 冻结）→ 卖家发货 →
  买家确认收货（或超时自动确认）→ 平台放款给卖家并自动扣佣金。
- Stripe Connect 支持"平台代收再分账"，买家只面对平台，卖家无需单独开户收款；
  支持全球主流卡 + Apple/Google Pay。
- 优点：交易闭环可控、佣金自动扣收、买家有保障，与现有"询盘报价→订单"结构衔接最顺。
- 前提与风险：
  1. 需海外公司主体（或 Stripe 支持地区的合法经营主体）才能开户；
     当前无主体是最大门槛；
  2. "代收+托管"在部分国家涉及资金监管（美国 Money Transmitter、欧盟 PSD2 等），
     起步建议小额交易 + 人工审核，规模化前再做合规评估；
  3. 拒付（chargeback）风险：需风控规则（新卖家冻结期、大额订单分批放款）；
  4. 汇率与结算：按美元结算，放款 T+2 起；部分国家卖家需当地收款账户。
- 费率估算：Stripe 国际卡约 2.9% + 0.3 美元/笔；平台佣金建议 3–5%，定价时叠加。

### 方案 C：专业第三方托管（Escrow.com / 银行信保）

- 平台把资金托管交给 Escrow.com 等专业服务商，成交后平台收佣金。
- 优点：合规与资金安全由托管方承担，适合大额 B2B（通常 1 万美元以上）。
- 缺点：流程割裂、托管费另计（约 1–3%）、买家体验下降、与平台 UI 融合度低。

| 对比项 | A 纯撮合 | B 平台代收（推荐） | C 第三方托管 |
| --- | --- | --- | --- |
| 上线速度 | 最快（1–2 周） | 中（主体到位后 4–8 周） | 中（对接 2–4 周） |
| 买家信任度 | 低 | 高 | 最高 |
| 佣金可控性 | 弱 | 强（自动扣） | 中 |
| 合规/牌照成本 | 无 | 中（需主体+风控） | 低（托管方承担） |
| 适合阶段 | 主体未定前的过渡 | 商业化起步 | 大额 B2B 规模化 |

**建议**：先选 B 起步；若短期无法解决海外主体，则先用 A 上线撮合与沟通功能，
主体到位后再无缝切换到 B。

## 11. 查漏补缺清单（上线前需逐项解决）

1. **收款主体**：无海外主体时 Stripe 无法开户；先决定 A 方案过渡或注册
   香港/新加坡/美国 LLC 主体。
2. **税务与合规**：目的国 VAT/GST 提示、出口管制与制裁名单筛查、
   跨境关税与物流清关提示。
3. **拒付与风控**：新卖家资金冻结期、大额订单人工审核、异常登录与设备风控。
4. **客服时区**：海外买家时差，初期 7×24 邮件 SLA + AI 客服兜底，再按时区排班。
 5. **商标与品牌**：BeanBeanMouse（豆豆鼠）商标检索（美国/欧盟/中国），防伪码与商标配套。
6. **数据合规**：GDPR（欧盟用户数据删除/导出、DPA）、CCPA、未成年人限制；
   服务器地域与数据存储位置需明确。
7. **多语言审核**：机器翻译"仅供参考"免责已上线；卖家发布内容需人工抽查，
   防止违规内容经多语言外溢。
8. **物流与保险**：跨境运费报价、物流轨迹回填、货损保险选项（建议接第三方）。
9. **无障碍与可访问性**：WCAG 2.1 AA 基础（对比度、键盘导航、图片替代文字）。
10. **冷启动运营**：先选 1–2 个垂直品类（如电子配件/家居用品）+ 1 个目标市场
    跑通闭环，再横向扩展。
11. **资金安全与审计**：托管资金与运营资金隔离、定期对账、审计日志（后端已具备）。
12. **上线后监控**：支付失败率、拒付率、翻译质量回访、邮件送达率、页面性能。
