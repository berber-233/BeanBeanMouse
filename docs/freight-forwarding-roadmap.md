# 货代功能路线图（Freight Forwarding）

> 平台后续可能承担货代角色。以下为分阶段设计，先以“物流信息透明化”为切入点，逐步扩展到货代服务。

## 阶段 A：物流信息透明化（本轮已实现）

- 卖家为订单创建物流单（承运商、运单号、起运地、目的地、ETA）；
- 卖家按节点更新状态（处理中→已打包→已发货→运输中→清关中→派送中→已签收/异常）；
- 买卖双方共享实时跟进动画与事件时间线；
- 物流关键事件自动进入第三方存证。

## 阶段 B：货代自助服务（建议）

- **在线订舱**：买家/卖家选择承运商（海运/空运/快递）并提交订舱申请；
- **报价试算**：按体积重、起运地与目的地预估运费与附加费（燃油附加、旺季附加）；
- **单据中心**：提单、装箱单、发票、原产地证、保险单的在线生成与下载；
- **报关协同**：报关行/货代上传报关回执，自动同步到订单时间线；
- **异常预警**：延误、甩柜、查验、破损时自动通知双方并记录存证。

## 阶段 C：平台货代（正式运营后）

- 平台与持牌货代合作，以代理身份订舱出单；
- 运费与杂费透明报价 + 平台担保支付；
- 货物保险在线投保（需持牌合作方）；
- 与主流物流跟踪 API（如 17TRACK、船公司 EDI）对接，自动拉取轨迹；
- 仓库收货（集货/拼箱）能力：按需接入海外仓与保税仓。

## 合规注意

- 无船承运人（NVOCC）/ 货代业务需相应资质（如中国无船承运人备案），正式开展前需完成主体与资质规划；
- 危险品、敏感货（锂电池、液体、粉末）需严格核验承运资质与申报；
- 运费代收代付涉及资金监管，建议与持牌支付/银行合作。
