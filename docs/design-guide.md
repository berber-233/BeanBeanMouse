# BeanBeanMouse 吉祥物设计规范（美工与审美基准）

> 说明：官方技能库暂无专门"美工/审美"技能（最近为 hatch-pet 角色工作流，已安装），
> 本规范把公开教程与参考资料中的审美要点沉淀为项目内基准，所有吉祥物/图标创作均按此执行。

## 1. 造型原则

1. **Q 版比例**：头身比 1:1 ~ 1.2:1，大头小身，整体圆润无棱角（Q 版/萌系第一原则）。
2. **特征极简**：只保留 2–3 个标志性特征，其余全部简化；特征必须在 64px 下仍可辨认。
3. **大眼小嘴**：眼睛放大、鼻子嘴最小化；高光让眼睛"有神"。
4. **线条统一**：同一形象描边粗细一致、颜色一致；线条圆头圆角，禁用折角硬边。
5. **配色克制**：主色 ≤ 2 种 + 点缀色 ≤ 2 种；优先取自网站色板。

## 3. 当前吉祥物（2026-09-11 AI 重制版）

- **形态**：Q 版金丝熊仓鼠「豆豆鼠」送货员——圆润大头小身、大圆耳（粉内耳）、鼓鼓颊囊、
  大眼高光、粉腮红、奶油白口鼻与腹部、金黄暖色毛发，背米色帆布运货袋（蓝色背带），红围巾；
- **背景**：暖米色平铺背景（`#F8E5C8`），与站点暖色主题一致；
- **出图标准**：**直接采用模型原始出图**（`doubao-seedream-5-0-pro-260628`），
  不做后期像素化 / 描摹；只允许等比缩放、居中裁切、格式转换；
- **文件**：
  - `assets/mascot-main.jpg`（1024px：OG、登录页、名片）
  - `assets/mascot-icon.png`（256px 圆形图标：导航 Logo、帮助浮标、帮助面板头像、favicon）
  - `assets/help-banner.jpg`（帮助面板横幅）
  - 母版：`outputs/art/mascot/*.jpg`
- **运输角色**（三位，每位 4 视角设定图 + 头像 + 场景视频）：陆运 / 海运 / 空运；
  **保险员角色已剔除**；
- **备注**：形象与动画每次重制后必须过一遍客观质检 + 前端回归，再由用户确认上线。

## 4. 创作流程（用户要求 + 2026-09-11 更新）

1. 先出多角度设定图（正 / 侧 / 背 / 四分之三视角，每位角色 4 张），确认造型一致；
   → 产物放 `docs/art/characters/`（不部署）；
2. 再出场景首帧（16:9，角色 + 载具），作为视频第一帧与页面封面；
3. 用首帧做图生视频（Seedance 2-5，5 秒、720p、`ratio adaptive`）产出页面上循环的动画；
4. 落位到 `assets/`（`work/build-art.ps1`，文件名固定，代码零改动优先）；
5. 每个版本必须：客观质检（`work/png-stats.mjs`、`work/video-info.mjs`）
   + 前端回归（`node test/verify.cjs`）+ 一致性自查（`node scripts/check-consistency.mjs`）。

## 5. 否决项

- 元素堆砌（帽子 + 扁担 + 旗子 + 多个道具同时出现）；
- 粗硬描边、尖角、杂线；
- 颜色超出色板的"荧光色 / 高饱和撞色"；
- 遮挡特征（如头发/帽子盖住颊囊或眼睛）；
- 在浮标/小尺寸下无法辨认的细节。

## 6. 像素风 UI（2026-09-11 起）

- **图标**：`assets/pixel/ui/*.png`（128px 透明 PNG），分类 10 个 + 通用 7 个（包裹/放大镜/盾牌/信箱/工具/用户/资讯）；
  出图统一用「像素画游戏 UI 图标 + 纯洋红 #FF00FF 背景」，再走 `work/key-icons.mjs` 抠透明，
  避免暖色背景与奶油白/金黄图标互相吃色。
- **控件质感**：方形硬边（圆角 ≤ 10px）、2px 描边、`Npx Npx 0` 阶梯投影、按下位移 2px；
  不用模糊阴影和渐变描边，保持像素游戏的"厚块"观感。
- **尺寸规范**：胶囊图标 22px、品类卡图标 34px、空状态图标 56px；一律带 `width/height` 与 `loading="lazy"`。
- **禁止**：在像素图标上叠加投影/发光/圆角遮罩；用 emoji 顶替已有像素图标的槽位。
