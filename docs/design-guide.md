# BeanBeanMouse 吉祥物设计规范（美工与审美基准）

> 说明：官方技能库暂无专门"美工/审美"技能（最近为 hatch-pet 角色工作流，已安装），
> 本规范把公开教程与参考资料中的审美要点沉淀为项目内基准，所有吉祥物/图标创作均按此执行。

## 1. 造型原则

1. **Q 版比例**：头身比 1:1 ~ 1.2:1，大头小身，整体圆润无棱角（Q 版/萌系第一原则）。
2. **特征极简**：只保留 2–3 个标志性特征，其余全部简化；特征必须在 64px 下仍可辨认。
3. **大眼小嘴**：眼睛放大、鼻子嘴最小化；高光让眼睛"有神"。
4. **线条统一**：同一形象描边粗细一致、颜色一致；线条圆头圆角，禁用折角硬边。
5. **配色克制**：主色 ≤ 2 种 + 点缀色 ≤ 2 种；优先取自网站色板。

## 2. 网站色板（所有角色必须相通）

| 角色 | 色值 | 用途 |

| 深蓝黑 | `#26304A` | 线条 / 头发 / 文字 |

## 3. 当前吉祥物（定稿：AI 仓鼠送货员）

- **形态**：AI 生成的 Q 版仓鼠——圆润身形、鼓鼓颊囊、大眼高光、粉腮红，
  背着塞满货物的运货袋（米色袋身 + 蓝色系带），整体可爱简洁；
- **背景**：暖米色平铺背景（约 `#F8E5C8`），与网站浅色基调（`#F5F7FB`）和谐；
- **文件**：`assets/mascot.jpg`（512px 网页用）、`assets/mascot-source.jpg`（1024px 高清原图）；
- **用途**：右下角帮助浮标（圆形裁切展示）；导航 Logo、favicon 与帮助面板头像
  使用 `assets/mascot-icon.png`（仓鼠圆形图标）；
- **备注**：用户已确认此形象为最终版，不再更改。

## 4. 创作流程（用户要求）

1. 先出多角度设定图（正 / 背 / 左 / 右 / 顶视 / 底视），确认造型一致；
2. 再做 2D 平面主视觉（正面线条版），用于网站浮标 / Logo / favicon；
3. 每个版本必须：Playwright 渲染 PNG + 关键像素采样校验 + 前端回归测试。

## 5. 否决项

- 元素堆砌（帽子 + 扁担 + 旗子 + 多个道具同时出现）；
- 粗硬描边、尖角、杂线；
- 颜色超出色板的"荧光色 / 高饱和撞色"；
- 遮挡特征（如头发/帽子盖住颊囊或眼睛）；
- 在浮标/小尺寸下无法辨认的细节。
