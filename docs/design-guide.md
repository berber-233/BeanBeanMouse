# BeanBeanDragon 吉祥物设计规范（美工与审美基准）

> 说明：官方技能库暂无专门"美工/审美"技能（最近为 hatch-pet 角色工作流，已安装），
> 本规范把公开教程与参考资料中的审美要点沉淀为项目内基准，所有吉祥物/图标创作均按此执行。

## 1. 造型原则

1. **Q 版比例**：头身比 1:1 ~ 1.2:1，大头小身，整体圆润无棱角（Q 版/萌系第一原则）。
2. **特征极简**：只保留 2–3 个标志性特征，其余全部简化；特征必须在 64px 下仍可辨认。
3. **大眼小嘴**：眼睛放大、鼻子嘴最小化；高光让眼睛"有神"。
4. **线条统一**：同一形象描边粗细一致、颜色一致；线条圆头圆角，禁用折角硬边。
5. **配色克制**：主色 ≤ 2 种 + 点缀色 ≤ 2 种；优先取自网站色板。

## 2. 网站色板（所有角色必须相通）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 深蓝黑 | `#26304A` | 线条 / 头发 / 文字 |
| 主蓝 | `#1D4ED8` | 点缀 / 配饰 / 腰带 |
| 强调金 | `#F59E0B` | 点缀 / 补丁 / 小物件 |
| 页面背景 | `#F5F7FB` | 浮标底色，融入页面 |
| 奶油白 | `#FFF6E8` | 火柴人头 / 浅色填充 |
| 浅黄棕 | `#F7D9A8` | 备用毛色（正式形象时使用） |
| 粉 | `#FFB9C4` / `#FF9E9E` | 点缀（腮红 / 内耳，正式形象时使用） |

## 3. 当前吉祥物（临时方案：火柴人送货员）

- **形态**：极简线条火柴人——圆头笑脸 + 线条身体 / 手臂 / 腿，无多余细节；
- **职业元素**：右手拎米色运货布袋（蓝提绳 + 金豆补丁），呼应"豆豆龙"与送货；
- **配色**：线条 #26304A、袋 #EAC9A0、提绳 #1D4ED8、补丁 #F59E0B、头 #FFF6E8；
- **用途**：右下角帮助浮标、导航 Logo、favicon；
- **备注**：临时方案；正式形象（仓鼠/龙娘等）经用户确认后再替换，
  替换时需同步本规范与 `assets/` 下的 SVG/PNG。

## 4. 创作流程（用户要求）

1. 先出多角度设定图（正 / 背 / 左 / 右 / 顶视 / 底视），确认造型一致；
2. 再做 2D 平面主视觉（正面线条版），用于网站浮标 / Logo / favicon；
3. 每个版本必须：Playwright 渲染 PNG + 关键像素采样校验 + 前端回归测试。

## 5. 否决项

- 元素堆砌（帽子 + 扁担 + 旗子 + 多个道具同时出现）；
- 粗硬描边、尖角、杂线；
- 颜色超出色板的"荧光色 / 高饱和撞色"；
- 遮挡特征（如头发/帽子盖住颊囊或眼睛）；
- 在浮标/小尺寸下无法辨认的细节。
